# Jelajah IPS Kelas IX

Permainan interaktif untuk buku *Ilmu Pengetahuan Sosial (Edisi Revisi) untuk SMP/MTs Kelas IX* — 3 bab, 10 pelajaran,
glosarium, galeri gambar, dan Uji Kompetensi, dengan suara alami bahasa Indonesia.

Situs: https://asem-saad.github.io/indonesia-edu/

Isi pelajaran berasal dari buku siswa IPS Kelas IX (Kemendikdasmen). Akun orang tua, anak, guru, dan kemajuan belajar disimpan di Supabase
dengan Row Level Security; kunci di `js/cloud.js` adalah kunci publik (publishable) yang memang boleh terlihat.
